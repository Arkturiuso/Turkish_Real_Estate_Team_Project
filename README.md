# Командный проект по определению цены на недвижимость в Турции
## Инструкции по запуску приложения
1. Перейдите в терминале в папку `app` внутри папки проекта: `cd app`
2. Скачайте все необходимые зависимости: `pip install -r requirements.txt`
3. Запуск приложения: `python -m streamlit run app.py` или `streamlit run app.py`
